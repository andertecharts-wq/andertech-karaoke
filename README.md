# AnderTech's Karaokê

Bem-vindo ao repositório do aplicativo de Karaokê profissional.

## Como Iniciar

1. Certifique-se de que todas as dependências estão instaladas:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Abra o navegador no link indicado (ex: http://localhost:5173).

## Funcionalidades Implementadas

- **Upload de Músicas**: Arraste suas músicas para criar karaokês instantâneos (Simulação IA).
- **Player Imersivo**: Letras sincronizadas e sistema de pontuação em tempo real.
- **Design Premium**: Interface Dark/Neon responsiva e moderna.
- **Navegação**: Sistema de rotas entre Home e Player.
- **Português**: Toda a interface traduzida para PT-BR.

## Estrutura do Projeto

- `/src/components`: Componentes reutilizáveis (Sidebar, PlayerBar, ScoreBoard).
- `/src/pages`: Páginas principais (Home, Player).
- `/src/index.css`: Estilização global e configuração do tema Neon.
